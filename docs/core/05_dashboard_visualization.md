# 5. Dashboard / Visualization

Tài liệu này hiện chỉ giữ ở mức outline cho MVP dashboard.

## 5.1 Mục tiêu

- Hiển thị kết quả annotation theo cách dễ đọc.
- Giữ được source link và evidence level.
- Cho phép truy vết annotation run.
- Nhắc rõ kết quả chỉ mang tính tham khảo, không phải chẩn đoán.

## 5.2 Core views

- Upload / run status.
- Clinical Variant Report.
- Pharmacogenomics Report.
- Population Frequency / Filtering.
- Research / Association Findings.
- Variant Detail Page.
- Annotation Run History.

## 5.3 Variant detail page

Cần hiển thị:

- Original input: rsID, chromosome, position, genotype, build.
- Normalized/mapped variant nếu có.
- Gene, consequence, transcript.
- Clinical/PGx/research annotations.
- Source links.
- Cảnh báo về build, allele, strand hoặc missing evidence.

## 5.4 Deliverables sau

- Wireframe dashboard.
- Summary cards theo priority.
- Findings tables.
- Filters theo category/source/priority.
- Variant detail page.
